# Junie Conversation Viewer

Junie Conversation Viewer is a Kotlin Multiplatform and Compose Multiplatform desktop application designed for reading, exploring, and searching conversation logs generated by the Junie agent.

## Features

- **Session Discovery & Management**: Automatically discovers and lists all Junie sessions from `~/.junie/sessions/`.
- **Top-Level Session Search**: Search across all discovered sessions globally with case-insensitive matching, snippet previews, resilient partial failure handling, and automatic query propagation upon opening a session (`Cmd+Shift+F` / `Ctrl+Shift+F`).
- **In-Conversation Search (`Search Messages`)**: Dedicated current-session search with match navigation, counts, and search highlighting (`Cmd+F` / `Ctrl+F`).
- **Asymmetric Human/Junie Layout**: Distinct visual styling for Human prompts and Junie responses, grouped by Turns.
- **Rich Content Rendering**: Syntax-highlighted code blocks, diff patches, terminal output, collapsible thoughts, tool calls, structured output, and error/warning blocks with copy buttons.
- **Granular Message Filtering**: Pill-shaped filter chips to toggle visibility of Human messages, Junie responses, Thoughts, Tools, Patches, and Terminal output.
- **Live Session Tracking**: Optional auto-refresh file watching with incremental parsing, scroll preservation, and auto-scroll at bottom.
- **Theming**: Light, Dark, and System theme modes with Material Design 3 and custom color palettes.

## Getting Started

### Prerequisites

- JDK 17 or later
- Gradle

### Running the App

To run the desktop application:

```bash
./gradlew run
```

### Testing

To run the test suite (JVM and common unit tests, ViewModel tests, and Compose UI tests):

```bash
./gradlew :shared:jvmTest test
```
